# Bundled meditation audio

`quiet-piano.m4a` is a 30-minute repeating, mono AAC adaptation of Erik Satie's
Gymnopédie No. 1, recorded by Wikimedia Commons contributor **Teknopazzo**.
The recording is released under **CC0 1.0**.

Source: https://commons.wikimedia.org/wiki/File:Gymnopedie_No._1..ogg
License: https://creativecommons.org/publicdomain/zero/1.0/
Changes: repeated to 30 minutes, reduced gain, final 12-second fade, AAC encoding.

`quiet.m4a` is generated silence, 30 minutes long, used as a native playback clock
for quiet meditations. Both tracks have a fixed end; the app seeks to the point
matching the selected session duration, so native playback ends without relying
on JavaScript timers running in the background.

`still-waters.wav` is an original, computer-synthesized 30-minute ambient track
created for this project using generated sine waves. No third-party recording is used.

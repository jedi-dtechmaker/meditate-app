# Meditate on the Word · Android

Expo SDK 58 / React Native / Expo Router.

See [the Android setup guide](../../docs/ANDROID_SETUP.md) for the new Supabase
project, environment variables, account redirects, development builds and APKs.

From the repository root, install with `npm ci`, then `npm run mobile`.
An installed development build is the target for native audio and reminders.
Sign-in is mandatory; supply real Supabase settings in this directory's `.env`.
